# pi-holz

## Git-Ablauf

- Wir benutzen keine Pull Requests, fertige Änderungen gehen direkt auf `main`.
- **Nicht pushen, bevor die Änderung lokal angeschaut wurde.** Nach einer Änderung erst Bescheid geben, wie man sie lokal ansieht (z. B. `npm run dev` oder die statische Vorschau unter `static/`), und auf ein ausdrückliches Okay warten („passt“, „pushen“). Erst dann committen und `git push origin main`.
